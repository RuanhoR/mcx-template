# MCX Template

## How to use?

First install nodejs and npm  

Go [Nodejs](https://nodejs.org)  

Next, install `mbler`

```bash
npm i -g mbler
```

Then, clone this repo if you install git
```bash
git clone https://github.com/RuanhoR/mcx-template.git
```
if you can't install git, plase click `code` button and download zip


Then, Build
```bash
mbler -c .
mbler build
```
